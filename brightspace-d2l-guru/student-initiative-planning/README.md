# Brightspace Student Experience Initiative

Co-ops at D2L are current university students. We use Brightspace at school, we build it at work. This group turns that into shipped changes.

Sponsored by John Baker (CEO). Additive to normal co-op work.

## Right now

- **Building** [Grade calculator sandbox](proposals/001-grade-calculator.md)
- **Proposed** [Code aware assignments](proposals/002-cs-course-support.md) for programming courses
- **Not ours** [Dark mode](research/dark-mode.md), already in implementation internally
- **Lead** Nakul Patel, Maverick

## Adding an idea

1. One liner in [idea-backlog.md](idea-backlog.md)
2. Raise it at the weekly sync
3. If it survives, copy `templates/proposal-template.md` into `proposals/` and open a PR
